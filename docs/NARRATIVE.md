# Narrative

Crea 定稿。主叙事走层 ①（拆 / 修决策故事）；Demo 只跑层 ② 闭环。层 ①、③ 在 v0 **不运行**。判定以 `demo/STORYBOARD.md` 与 `tests/GOLDEN_CASES.md`（G01–G08）为准，口播不得改阈值、不得改金样预期。

**锁死阈值：** 裂缝 `crack_mm > 3` mm；倾斜 `tilt_deg > 0.5`°。不得现场发明第三条规则。

---

## One-liner（一句话价值）

人不爬危楼：把本场裂缝与倾斜读数变成可复核的证据链——只点亮超阈值部位，缺依据就 BLOCK，把拆还是修交给签字工程师。

---

## 主叙事 ①

### 场景痛点

土木正在从「大规模新建」转向「既有建筑运维」。危房排查、震后初勘、老旧小区整治，真正卡住现场的不是报告模板，而是**人必须上危楼采证**：爬架、贴近裂缝、手持倾角仪，贵、慢、险。纸面本子把毫米缝和度数倾写在一起，阈值靠口头，结论靠事后补圆——未超限的点与超限的点「看起来都有问题」，复测排不出队，签字工程师拿到的是一堆无法复核的话。

### 产品故事

我们先把人从危楼上请下来。无人方式采证（传感器 / 影像量测 / 无人机，后期一律写入同一套 `InspectionReading`），系统只做三件事，而且件件可复核：

1. **损伤定位** — 只标出真正超阈值的部位；未超限的点保持安静，不制造恐慌。
2. **维修优先级** — 超限点稳定排序，并挂上复检任务，现场知道先看哪里。
3. **证据链** — 读数、阈值、规则编号、时间戳可回放；缺任何必填字段就 **BLOCK**，绝不编造结论。

拆还是修，是层 ① 要对签字工程师讲的故事，也是路演的主叙事。**本版不替工程师做这个决定**：v0 交出去的是证据链，不是竣工验收，不是结构鉴定，更不是法定签字。层 ③（证据包 / 平面导出）排在证据链稳定之后。人不用上危楼；系统也不用上签字栏。

> 视觉隐喻：危楼仍在，人退到地面；平面上只有超限点亮起来，其余保持暗。底部抽屉打开的是链条，不是故事。

## Demo 话术卡 ②

四拍，对齐 `demo/STORYBOARD.md`。左手导入、中心平面标记、右侧排序列表、底部证据抽屉。只跑层 ②：`ingest → flag → rank → attach`。

| 拍 | 动作 | 口播要点 | 画面必须看到 |
| --- | --- | --- | --- |
| **1. 导入 mock** | 导入 `data/mock/g01.json` | 「先导入本场检测 JSON。左边是读数批次，不是聊天框。」 | 左栏三条：A 裂缝 4.2 mm / B 倾斜 0.2° / C 裂缝 1.0 mm。中心平面仍安静。 |
| **2. 标超阈部位** | 跑 ingest → flag | 「裂缝大于 3 毫米、倾斜大于 0.5 度才告警。只有超阈的点会亮。」 | **只亮 A**。B、C 保持暗。右栏列表长度 = 1。 |
| **3. 优先级 / 复检** | 切 `g02.json`，再切 `g03.json` | 「倾斜超 0.5，排出优先级并生成复测。两处超限则排序稳定，再导一次顺序不变。」 | G02：P1 单点 + `recheck:P1:tilt_deg`。G03：两处标记，右栏 **E-corner → N-wall**，复导同序。 |
| **4. 点开证据链** | 点击 A 或列表首行，打开底栏抽屉 | 「读数、阈值、规则、时间戳都在这里。缺依据不给结论。」 | 抽屉展示：`value` / `threshold` / `rule_id` / `timestamp` / `conclusion` / `confidence`。明确说出：**无依据 → BLOCK，绝不编造结论。** |

**话术禁区（与 storyboard「镜头前禁止」一致）：**

- 不得点亮 G01 未超阈的 B / C
- 不得对空批次编造假点（G04）
- 抽屉文案不得缺少 `threshold` / `rule_id`
- 不得真的跑层 ① 或层 ③

## 相对套壳差别

这不是「泛建筑问答」：不能对任意危房照片聊天出鉴定，也不能用模型记忆填阈值。

| 套壳常见做法 | 本项目 |
| --- | --- |
| 开放域建筑知识问答 | **封闭域**：本场只吃本场 `InspectionReading` JSON，不引入场外知识当证据 |
| 阈值写在 Prompt 里，每次说法不同 | 阈值锁死在规则表：`crack_mm > 3`、`tilt_deg > 0.5`；未知 metric **禁止发明规则** |
| 缺字段也「生成一段专业结论」 | 缺任一证据必填字段 → **BLOCK**（0 SILENT_FAIL） |
| Demo 不可复现、不可打分 | G01–G08 金样可回归；同一输入两次结论必须相同（G08） |
| 把 LLM 输出当成签字 | 层 ② 只产出告警、排序与证据链；签字仍是持证工程师的事 |

评委可问的一句话：「你们和 ChatGPT 套个危房 Prompt 有什么不同？」答：**输入是本场读数，输出是可复核的证据链；超阈才亮，缺据就停，金样能打分。**

## 60–90s 路演口播草稿

对齐 storyboard 节拍。中段用「A 点亮、未超阈点保持安静」做反差。收尾打开证据抽屉，再用克制的一层 ① tease：**下一步可出拆/修建议，本版未真跑决策。**

**0–8s　导入**

> 导入本场检测读数。左边三条：A 裂缝 4.2 毫米，B 倾斜 0.2 度，C 裂缝 1.0 毫米。平面上现在什么都没亮——我们还没有判定。

**8–20s　反差：只亮 A**

> 规则很窄：裂缝大于 3 毫米，倾斜大于 0.5 度，才告警。A 超了，点亮。B 和 C 没超，保持安静。右侧列表只有一行。未超限的点，我们不制造恐慌。

**20–35s　倾斜 + 复测**

> 换一批。P1 倾斜 0.8 度，超过 0.5。系统排出优先级，并生成复测任务。先复检这里，而不是把整栋楼重新爬一遍。

**35–50s　两处超限，顺序稳定**

> 再换一批，两处都超限：东角倾斜、北墙裂缝。排序稳定——东角在前、北墙在后。同样的输入再导一次，顺序不变。可打分，可回归。

**50–70s　证据抽屉**

> 点开 A，底部抽屉给出证据链：读数、指标、数值、阈值、规则编号、时间戳、结论、置信度。缺任何一个必填字段，这里会 BLOCK，不会编一段「看起来很专业」的鉴定词。无依据，不给结论。

**70–90s　tease ① + 免责（克制收束）**

> 拆还是修，是下一步可以交给签字工程师的建议——决策层 ①，本版未启用，我们没有真跑这个决策。今天交到手里的，是可复核的证据。本系统辅助决策，不替代签字工程师。

**配音备注：** 中段「点亮 / 安静」各停半拍；抽屉特写读出 `rule.crack_mm.gt_3` 或阈值数字之一即可，不要念完整 Schema。结尾「未启用」与 Disclaimer 同屏，不要切进任何决策 UI。

## PPT 可抽页提纲

五页即可抽进路演 PPT。不要加第六页「我们已经自动给出拆/修」。

1. **痛点**  
   既有建筑运维 ← 人上危楼采证：贵、慢、险。纸面阈值、事后补写、无法复核。

2. **闭环示意（v0 = 层 ②）**  
   读数 JSON → ingest → flag → rank → attach → 证据链或 BLOCK。旁注：① 决策、③ 导出 = 后续；流水线顺序 ② → ① → ③。

3. **Demo 四步**  
   导入 mock → 只标超阈部位 → 优先级 / 复检 → 点开证据链。配 G01 反差图：A 亮、B/C 暗。

4. **证据链特写**  
   必填字段墙：`reading_id` / `sensor_or_point` / `metric` / `value` / `threshold` / `rule_id` / `timestamp` / `location_tag` / `conclusion` / `confidence`。缺一即 BLOCK。阈值锁死：> 3 mm、> 0.5°。

5. **①③ 路线图**  
   ① 主叙事：拆 / 修建议，人在环内，持证工程师签字。③ 证据包 / 平面 / 工单导出。v0 只 tease，不运行。硬件后期仍写入同一 `InspectionReading`。

## Disclaimer

**本系统用于辅助决策，不替代签字工程师。**

本仓库 v0 只锁定层 ②（引擎）：告警、排序与证据链。它们**不是**竣工验收、**不是**房屋安全鉴定、**不是**抗震鉴定、**不是**危房等级判定，也**不是**任何法定签字结论。

- 不得将层 ② 的输出表述为「建议拆除」或「建议维修」的正式意见。拆 / 修是层 ① 的叙事，**本版未启用、未运行**。
- 不得在演示中进入决策 UI，或用模型补全缺失的 `threshold`、`rule_id`、`conclusion`、`confidence` 来「把 Demo 跑顺」。
- 现场使用必须由持证工程师复核原始读数与规则命中；本系统是辅助决策工具，不能代替执业资格与法定程序。
- 无依据即 BLOCK。零静默失败。不编造读数、不编造阈值、不编造结论。
